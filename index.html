Music DJ App · Root

Privacy Policy

Effective October 11, 2026 · Test version 1.0.0

Music DJ App is currently an audio playback test App. It delivers a short, generated test tone through Root so we can check playback, buffering, and seeking. This version does not provide a commercial music catalog or a shared listening queue.

Data the App processes

When you open the App, Root provides the connection and community context needed to run its client and server. An audio request sent by the App contains a byte offset and requested chunk size. The server uses those values to return part of the test audio file. The App does not use your Root account identifier to build a profile, and its code does not save audio requests or listening history in an App database.

This version does not ask for or process your microphone or voice-channel audio, messages, contacts, uploaded files, payment information, or precise location. It does not use advertising or analytics trackers in its own code.

How data is used and shared

Audio request data is used only to deliver the test audio and operate the App. Root hosts the App client and server and routes their communications. Root may process technical data and operational logs under Root's Privacy Policy. The current App does not send App data to an external music provider or another developer-operated service, and we do not sell App data.

This policy page is hosted by GitHub Pages. Visiting it may cause GitHub to process website usage data, including your IP address, under GitHub's Privacy Statement.

Retention and deletion

The App does not intentionally retain personal data or listening history after an audio request is served. Root may retain platform operational records according to its own policies. If you contact us about privacy, we use your message to respond and keep it only as long as needed to handle the request or meet a legal obligation.

To ask about App data, request access or deletion, or report a privacy concern, email eliekanaan757@gmail.com. For data held by your Root account or the Root platform, use Root's privacy controls or contact Root directly. If a community uninstalls the App, the App will not retain community data outside Root's hosted runtime.

Changes

We will update this policy before adding features that change data handling, such as a licensed music catalog, shared queue, user accounts, or external service providers. The effective date above will change when the policy changes.
